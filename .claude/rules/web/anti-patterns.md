# Web — Current Anti-patterns (Do Not Follow)

- **`extractMessage()` is copy-pasted across 13 `*.action.ts` files (as of Jul 2026), with 3 diverging implementations.** Most take `(error: unknown, fallback: string)` and check `error instanceof Error`; `users.action.ts` hardcodes its own Vietnamese fallback instead of taking one; `departments.action.ts` types the param as `any` and skips the `instanceof Error` check, silently swallowing real error messages on non-Axios failures. **Don't add a 14th copy.** When you touch an action file, extract this into a shared `lib/extractMessage.ts` instead of pasting another variant.
- **`proxy.ts` has a dead/misleading route entry**: `/job-postings` is listed in `roleProtectedPaths.candidate` but is intentionally *not* in `privatePaths` (it's a public route, per `(public)/job-postings`) — so that allowlist entry is never actually consulted. Don't copy this entry as a template for a new protected route; copy from a route that's genuinely gated (e.g. `/dashboard`) and remember to add to **both** `privatePaths` and the role's array.
- **Admin's `roleProtectedPaths` is missing `/interviews`**, which recruiter has — asymmetric in a way that looks accidental rather than a deliberate access decision. Confirm intent before mirroring this gap when adding new admin routes.
- **Tailwind has no design-token layer**: `tailwind.config.js`'s `theme.extend` is empty, there's no `cn()`/`clsx`/`tailwind-merge` anywhere in the codebase, and there is no shared UI primitive component (see `directory-structure.md`). The result is ~2,350 raw arbitrary hex classes (`bg-[#0071E3]`, `text-[#1D1D1F]`, etc. — a consistent Apple-HIG-style palette, just never centralized) and ~400 occurrences of `style={{ fontFamily: SF }}` (from `types/fonts/fonts.ts`) across ~135 files (as of Jul 2026 — growing, re-count before citing). **Don't add more raw hex/inline-font copies.** If you're touching a component that needs one of the existing recurring colors, that's the moment to register it in `tailwind.config.js` (`theme.extend.colors`/`fontFamily`) rather than pasting the hex string again — do this incrementally, not as a big-bang rewrite.
- **`src/app/global.css` is still the unmodified Nx/Next scaffold stylesheet** (`#hero`, `#nx-console`, `#nx-cloud`, `#welcome`, `.list-item-link`, etc.) — dead weight from `nx g @nx/next:app`, unrelated to the actual product. Safe to delete; don't treat it as live global styling or add real app CSS into it.
- **Notification store hydration is a one-off variant of the hydrator pattern**: `NotificationDropdown.tsx` takes `initialNotifications`/`initialUnreadCount` as props and pushes them into `useNotificationStore` via its own inline `useEffect`, instead of a dedicated hydrator component. Acceptable as prior art for a small, single-consumer store, but don't use it as the template for a new cross-page store — use a real hydrator component (see `code-conventions.md`) for those.
